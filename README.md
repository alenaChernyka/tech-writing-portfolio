## OpenAPI TVmaze

[TVmaze API](https://www.tvmaze.com/api#licensing) — публичный REST API с данными о телесериалах без официальной OpenAPI-спецификации.

Я изучаю документацию TVmaze, тестирую API в Postman и создаю OpenAPI-спецификацию в Swagger Editor. Особое внимание уделяю структуре документации, переиспользованию компонентов и подробному описанию схем данных.

Сейчас полностью описано 9 из 28 эндпоинтов: параметры запросов, возможные ответы, схемы данных и примеры запросов и ответов. Спецификация проверена на соответствие фактическому поведению API.

Спецификация опубликована в Swagger UI и может использоваться как машинно-читаемая документация API.

**Документация:**

- [OpenAPI](./tvmaze-openapi/openapi.yml)
- [Swagger UI](https://alenachernyka.github.io/tech-writing-portfolio/tvmaze-openapi/)
- [Decisions](./tvmaze-openapi/decisions.md)
