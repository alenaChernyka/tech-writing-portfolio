## OpenAPI TVmaze

[TVmaze API](https://www.tvmaze.com/api#licensing) — публичный REST API с данными о телесериалах, эпизодах, актерах, съемочных командах и расписании трансляций. У проекта нет официальной OpenAPI-спецификации.

Я изучаю документацию TVmaze, тестирую API в Postman и создаю OpenAPI-спецификацию в Swagger Editor. Особое внимание уделяю структуре документации, переиспользованию компонентов и подробному описанию схем данных. При работе использую ИИ-ассистента для доработки формулировок, проверки текста и создания черновых схем данных на основе ответов API. Полученные результаты проверяю и дорабатываю самостоятельно.

Сейчас полностью описано 9 из 28 эндпоинтов: параметры запросов, возможные ответы, схемы данных и примеры запросов и ответов. Спецификация проверена на соответствие фактическому поведению API.

Спецификация опубликована в Swagger UI и может использоваться как машинно-читаемая документация API.

* [Swagger UI](https://alenachernyka.github.io/tech-writing-portfolio/tvmaze-openapi/)
