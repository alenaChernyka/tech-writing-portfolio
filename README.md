## Документация для разработки мобильного приложения «Полка»
 
«Полка» — мой личный проект, приложение для учета домашних запасов. Я подготовила для его разработки комплект документации. Продуктовый бриф и журнал решений в реальной команде обычно ведет продакт-менеджер или аналитик; я написала их сама, чтобы у документации был реалистичный контекст. На основе брифа я выстроила терминологию, функциональную спецификацию и остальные материалы, собранные ниже.
