Список документов, которые пока не нужны, но могут понадобиться по мере развития проекта. Когда триггер срабатывает — документ заводится по-настоящему, с номером в основной иерархии, а строка ниже помечается как "Создан".

|Документ|Зачем нужен|Триггер к созданию|Статус|

|Модель данных|Описать поля, типы и структуру хранения для разработки|Начинаем писать код и нужна зафиксированная структура, а не только поведение из функциональной спеки|Не начат|
|Сценарии проверки|Зафиксировать, как проверять, что каждая функция работает как задумано|Появляется первая рабочая версия приложения, которую можно тестировать|Не начат|
